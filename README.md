# Organización de un concierto – Scrum y Kanban

## Descripción del proyecto
Este proyecto tiene como objetivo planificar y organizar un concierto utilizando las metodologías ágiles Scrum y Kanban.

## Objetivo
Organizar un concierto de forma eficiente, coordinando las tareas necesarias para su realización.

## Historias de usuario
El proyecto incluye las siguientes actividades:

- Seleccionar el lugar del concierto.
- Contratar a los artistas.
- Organizar la venta de entradas.
- Organizar la seguridad del evento.

## Metodología Scrum
Se ha creado el **Sprint 1 – Organización del concierto**, con historias de usuario, criterios de aceptación y estimaciones.

## Tablero Kanban
Las tareas se organizan en tres estados:

- **Todo:** tareas pendientes.
- **En progreso:** tareas que se están realizando.
- **Hecho:** tareas finalizadas.

## Seguimiento
Se utiliza un gráfico Burndown para visualizar el trabajo pendiente y controlar el avance del proyecto.

## Herramienta utilizada
GitHub Projects.
